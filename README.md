# Logica-programacion-2

# Instrucciones del Ejercicio de lógica de programación 2

Crea un programa en **JavaScript** que realice las siguientes tareas:

1. **Solicitud de datos:** Solicita al usuario la temperatura en grados Celsius (mediante `prompt` o un campo `<input>`).
2. **Validación de entrada:** Identifica si el dato ingresado es un número válido (`number`). Si no lo es, muestra un mensaje de error y vuelve a solicitar el dato.
3. **Conversión de unidades:** Convierte la temperatura ingresada de grados Celsius a:
   * **Grados Kelvin**
   * **Grados Fahrenheit**
4. **Muestra de resultados:** Imprime ambos resultados a través de la consola (`console.log`) o desplegados en el DOM.

---

## Casos de Prueba

Prueba tu programa con las siguientes entradas para verificar su correcto funcionamiento:

### Prueba 1
* **Entrada:** `45`
* **Salida esperada:**
  * **Grados Kelvin:** `318.15`
  * **Grados Fahrenheit:** `113`

### Prueba 2
* **Entrada:** `14`
* **Salida esperada:**
  * **Grados Kelvin:** `287.15`
  * **Grados Fahrenheit:** `57.2`

> **Sugerencia:** Realiza pruebas adicionales con otros valores numéricos para asegurar la robustez de tu código.
